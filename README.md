# Cognitive Kids 🧠

Полноценное мобильное приложение для развития когнитивных способностей у детей дошкольного возраста (2-6 лет).

## 📱 О проекте

Cognitive Kids - это образовательная платформа, которая помогает детям развивать важные когнитивные навыки через игру. Приложение включает в себя 7 специально разработанных игр, систему мотивации и детальную аналитику прогресса.

## 🎯 Основные возможности

### Для Администраторов
- 👥 Управление пользователями
- 📊 Общая статистика приложения
- 🔐 Создание аккаунтов родителей
- 📈 Мониторинг активности

### Для Родителей
- 👶 Создание профилей детей
- 📊 Просмотр детальной статистики
- 💡 Персональные рекомендации
- 📈 Отслеживание прогресса

### Для Детей
- 🎮 7 развивающих игр
- 👥 Система друзей
- 🏆 Таблица лидеров
- ⭐ Система очков и достижений

## 🎮 Игры

1. **Мемори (Memory/Pairs)** - Развитие зрительной памяти
2. **Найди лишнее (Odd One Out)** - Логическое мышление
3. **Сортировка (Sorting)** - Классификация предметов
4. **Счет (Counting)** - Математические навыки
5. **Тени и Силуэты (Shadow Matching)** - Зрительное восприятие
6. **Построй по Образцу (Building)** - Пространственное мышление
7. **Что будет дальше? (Predicting)** - Причинно-следственные связи
8. **AR Приключение (AR Adventure)** 🆕 - Дополненная реальность (Unity)

## 📦 Установка и запуск

### Требования
- Node.js (v14+)
- npm или yarn
- Expo CLI (для мобильного приложения)

**Примечание:** MongoDB больше не требуется! Используется SQLite - встроенная база данных в одном файле.

### 1. Клонирование репозитория
```bash
git clone <repository-url>
cd cognitive-kids
```

### 2. Установка Backend

```bash
cd backend
npm install

# Создайте файл .env
# PORT=5000
# DB_PATH=./database.sqlite
# JWT_SECRET=your_secret_key
# NODE_ENV=development

# Создайте администратора (БД создается автоматически)
node scripts/createAdmin.js

# Запустите сервер
npm run dev
```

Сервер будет доступен на `http://localhost:5000`

**Учетные данные администратора:**
- Username: `admin`
- Password: `admin`

### 3. Установка Mobile приложения

```bash
cd mobile
npm install

# Настройте API URL в src/config/api.js
# Для Android эмулятора: http://10.0.2.2:5000/api
# Для iOS симулятора: http://localhost:5000/api
# Для физического устройства: http://<YOUR_IP>:5000/api

# Запустите приложение
npm start

# Проверка готовности Unity интеграции (для AR игры)
npm run check-unity
```

### 4. Unity AR Игра (опционально)

AR игра готова к интеграции. Для добавления Unity AR модуля:

```bash
# Прочитайте руководство
cat UNITY_INTEGRATION_GUIDE.md

# Проверьте готовность
cd mobile
npm run check-unity
```

**Примечание:** AR игра требует:
- Unity 2022.3 LTS+
- ARCore (Android 7.0+) / ARKit (iOS 14+)
- Физическое устройство (эмуляторы AR не поддерживают)

Подробная инструкция: [UNITY_INTEGRATION_GUIDE.md](./UNITY_INTEGRATION_GUIDE.md)

```

## 📱 Тестирование

### Тестовый workflow:

1. **Вход как Администратор:**
   - Username: `admin`
   - Password: `admin`
   - Создайте родителя (например: `parent1` / `password123`)

2. **Вход как Родитель:**
   - Используйте учетные данные, созданные админом
   - Создайте профиль ребенка
   - Укажите имя, возраст (2-6 лет), логин и пароль

3. **Вход как Ребенок:**
   - Используйте учетные данные ребенка
   - Играйте в игры
   - Добавляйте друзей
   - Смотрите таблицу лидеров

4. **Просмотр статистики (Родитель):**
   - Вернитесь в аккаунт родителя
   - Просмотрите статистику ребенка
   - Получите рекомендации

## 🎨 Особенности реализации

### Адаптивность по возрасту
Все игры автоматически адаптируются к возрасту ребенка:
- **2-3 года:** Упрощенные задания, меньше элементов
- **4-5 лет:** Средняя сложность
- **6 лет:** Максимальная сложность

### Система рекомендаций
Алгоритм анализирует результаты ребенка и генерирует персональные рекомендации:
- Определяет слабые стороны
- Предлагает новые игры
- Хвалит за успехи

### Система мотивации
- Очки за каждую игру
- Соревнование с друзьями
- Таблица лидеров
- Визуальная обратная связь

## 🔐 Безопасность

- Хеширование паролей (bcryptjs)
- JWT токены для аутентификации
- Проверка прав доступа
- Защита роутов по ролям
- Валидация данных

## 📊 API Документация

Полная документация API доступна в `backend/README.md`

### Основные эндпоинты:

**Аутентификация:**
- `POST /api/auth/login` - Вход
- `GET /api/auth/me` - Текущий пользователь
- `POST /api/auth/register-parent` - Регистрация родителя
- `POST /api/auth/register-child` - Регистрация ребенка

**Игры:**
- `POST /api/games/result` - Сохранить результат
- `GET /api/games/statistics/:childId` - Статистика
- `GET /api/games/leaderboard` - Таблица лидеров

**Друзья:**
- `POST /api/friends/request` - Запрос в друзья
- `GET /api/friends` - Список друзей
