## 📖 О проекте

AR Игры - это современное образовательное приложение с дополненной реальностью, разработанное специально для детей дошкольного возраста. Через камеру мобильного устройства дети взаимодействуют с виртуальными объектами и реальным миром, выполняя задания, которые развивают различные когнитивные навыки.

### 🎯 Образовательные цели

Каждая игра направлена на развитие конкретных навыков:
- 🧠 Логическое мышление
- 🎨 Распознавание цветов
- 📏 Понимание размеров
- 🔢 Навыки счета
- 🗂️ Категоризация
- 👁️ Пространственное мышление

## 🎮 Игры

### 1. ✋ Покажи число
Ребенок должен показать на пальчиках число, которое видит на экране (от 1 до 10).
- **Навык**: Счет, моторика, координация
- **Сложность**: ⭐⭐☆☆☆
- **AR взаимодействие**: Ребенок использует свои руки для ответа

### 2. 🎨 Покажи цвет
Нужно найти предмет определенного цвета в реальном мире и показать его в камеру.
- **Навык**: Распознавание цветов, взаимодействие с окружением
- **Сложность**: ⭐⭐☆☆☆
- **AR взаимодействие**: Поиск цветов в реальной обстановке

### 3. 🐷 Найди свинку
Свинка прячется в разных углах экрана, нужно найти и нажать на нее.
- **Навык**: Внимание, наблюдательность, быстрота реакции
- **Сложность**: ⭐⭐☆☆☆
- **AR взаимодействие**: Поиск объектов на экране

### 4. 🍎 Посчитай фрукты
Над головой появляются фрукты (AR эффект как в TikTok/Instagram), нужно их посчитать.
- **Навык**: Навыки счета, концентрация внимания
- **Сложность**: ⭐⭐⭐☆☆
- **AR взаимодействие**: Виртуальные объекты "над головой"

## 🚀 Быстрый старт

### Предварительные требования

- Node.js 16+ и npm
- Мобильное устройство с камерой (для AR)
- HTTPS (обязательно для доступа к камере)

### Установка

```bash
# Клонируйте репозиторий
git clone https://github.com/yourusername/ar-learning-games.git

# Перейдите в директорию
cd ar-learning-games

# Установите зависимости
npm install

# Запустите проект
npm run dev
```

Приложение будет доступно по адресу `https://localhost:3000`

### 📱 Доступ с мобильного устройства

1. Убедитесь, что компьютер и телефон в одной Wi-Fi сети
2. Узнайте IP адрес компьютера (`ipconfig` на Windows или `ifconfig` на Mac/Linux)
3. На мобильном устройстве откройте `https://[IP-адрес]:3000`
4. Примите предупреждение о сертификате (только для разработки)
5. Разрешите доступ к камере

## 🎨 Кастомизация

### Изменение цветовой схемы

Отредактируйте CSS переменные в `src/index.css`:

```css
:root {
  --primary-green: #8BC34A;
  --primary-brown: #795548;
  --primary-yellow: #FFC107;
  /* ... */
}
```

### Добавление новых игр

1. Создайте компонент игры в `src/components/games/`
2. Добавьте игру в массив games в `FarmHome.jsx`
3. Добавьте обработчик в `GameContainer.jsx`

См. подробные инструкции в [INTEGRATION.md](INTEGRATION.md)
